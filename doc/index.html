MULAI CEPAT 02

UI pertama

Mulai dari Window, susun layout, lalu tambahkan kontrol.

src/App.tsxTypeScript 
import { Application, Window, View, Column, Text } from "@jsdesk/core";

export default function App() {
  return Window({
    title: "Jsdesk",
    width: 960,
    height: 640,
    style: { backgroundColor: "#F3F5F2" },
    body: View({
      style: {
        position: "center",
        width: 460,
        padding: 32,
        backgroundColor: "#FFFFFF",
        borderRadius: 18,
      },
      children: [
        Column({
          spacing: 14,
          children: [
            Text({ value: "Halo, dunia." }),
            Text({ value: "UI desktop dari App.tsx." }),
          ],
        }),
      ],
    }),
  });
}

Application.start(App);
i

Kontrak UI saat ini: compiler membaca pemanggilan komponen dan properti statis dari App.tsx. Ini bukan browser DOM; style dipetakan ke atribut XAML.

KOMPONEN 04 06

Navigasi halaman

Route map adalah konfigurasi. Tombol hanya ada jika ditulis sebagai Button.

NavigationStack + aksi eksplisitNavigation 
function HomePage() {
  return Column({
    children: [
      Text({ value: "Beranda" }),
      Button({
        text: "Buka pengaturan",
        onPress: () => Navigate("/settings"),
      }),
    ],
  });
}

function SettingsPage() {
  return Column({
    children: [
      Text({ value: "Pengaturan" }),
      Button({ text: "Kembali", onPress: () => GoBack() }),
    ],
  });
}

NavigationStack({
  initialRoute: "/home",
  routes: {
    "/home": HomePage,
    "/settings": SettingsPage,
  },
})
!

Route pertama pada object routes saat ini menjadi halaman awal yang terlihat. initialRoute belum digunakan untuk memilih halaman awal oleh generator WPF. Parameter kedua Navigate(path, params) juga belum diteruskan ke halaman generated.

Nilai angka ukuran WPF tidak memakai unit px. Untuk margin/padding berbentuk string, angka dan akhiran px diterima sebagai angka WPF. Style CSS lain yang belum tercantum tidak otomatis diterapkan.

CATATAN IMPLEMENTASI 09

Batasan yang perlu diketahui

API bertumbuh bertahap; bagian ini membedakan props tersedia dari perilaku yang sudah aktif.

01

Subset style, bukan CSS penuh. Tidak ada selector, cascade, pseudo-class per komponen, flex/grid CSS, atau CSS file untuk UI WPF.

02

TextInput belum interaktif. Generator menulis nilai awal ke TextBox, tetapi placeholder dan callback onChange belum diterapkan.

03

Route awal mengikuti urutan object. Route pertama yang dideklarasikan ditampilkan saat aplikasi mulai; initialRoute belum mengubahnya.

04

Parameter navigasi belum masuk ke page. Handler generated memakai path untuk menampilkan route, tetapi belum mengirim params ke komponen halaman.

05

Gunakan nilai statis. Compiler saat ini mengonversi object props literal dan callback navigasi yang dikenali, bukan runtime React atau state hooks.
